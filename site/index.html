Made for talking to coding agents.

Claude Code, Cursor and the terminal are where most of your words go now. These features are for them.

Reply to a waiting agent

A Claude Code hook tells Mouthpiece when an agent is waiting for you. Press ⌃⌥R, answer out loud, and the reply lands in that agent's window while you stay where you were.

Knows your codebase

Names come from the repo you're in, so "the paste text function in the paste file" comes out as paste_text in @src-tauri/src/paste.rs.

Transcribes while you talk

Each phrase is transcribed at the pause after it. Long pauses cost nothing, and the text is ready a quarter of a second after you stop.

"Send it." "Attach the error."

Submit the prompt, add your latest stack trace as a code block, or say "scratch that" to take back the last paste.

Learns your corrections

History keeps what you said next to the cleaned-up text. Fix the same word twice and it offers to remember it.

Something else? Open an issue.

macOS says Mouthpiece can't be opened, or is damaged.

Mouthpiece isn't notarized by Apple yet, so macOS blocks the first launch. Open it once, then go to System Settings → Privacy & Security, scroll down and click Open Anyway. On macOS 14 or earlier, right-click the app and choose Open instead.

To skip that step entirely, install with the one-line command or build it from source.

Versions before 0.3.1 show "damaged" instead. Download the latest version, or run xattr -dr com.apple.quarantine "/Applications/Mouthpiece.app" in Terminal.

Is it safe? Could it contain malware or leak what I say?

Mouthpiece is open source, so anyone can read exactly what it does. What we check:

  • Your voice stays on your Mac. Speech recognition and the optional cleanup both run locally. The list above is every connection the app makes, and none of them carry what you say.
  • No cloud models. Ollama can run some models on its own servers. Mouthpiece hides those and refuses to use them, so cleanup never leaves your Mac.
  • Your transcripts are yours. History stays on your Mac in a file only your account can read. You can lock it behind Touch ID or your password, and logs leave out what you said unless you turn that on.
  • Dependencies are scanned. Every change is checked against the public databases of known vulnerabilities in the libraries the app uses, and the build fails if one turns up.
  • Downloads are verified. Speech models are checked against known checksums, and updates must carry our signature before they install.

The realistic risk is the one every app has: bugs. Mouthpiece types into other apps and listens while you hold the key, so a bug could put text in the wrong place. If you hit one, please open an issue.

Do I need Ollama?

No. Without it you still get formatting for each app, casing commands, file tags, lists, punctuation and snippets. Ollama adds an optional cleanup pass for rambling or casual speech, and it also runs on your Mac. Ollama's cloud models are hidden and never used, to keep your text private.

How do I connect it to Claude Code?

Open Settings → Coding agents, copy the hook config, and add it to ~/.claude/settings.json. From then on, the widget shows when an agent is waiting, and ⌃⌥R records your reply.

Which apps does it work in?

Any app you can paste into. Terminals, Claude Code, Cursor, VS Code, Slack, email and browsers each get their own formatting, and you can set a mode for any other app.

Does it work on an Intel Mac?

No. It needs Apple Silicon (M1 or later), whose GPU runs the speech model fast enough to feel instant.

Other languages?

English only for now. The speech models it ships with are tuned for English, which keeps them small and quick.

Other ways to install

Mouthpiece isn't notarized by Apple yet (that costs $99 a year), so a download from the button above needs the one-time "Open Anyway" step. These two skip it.

One-line install

Paste into Terminal. It downloads the same DMG from GitHub, checks the app's signature and copies it into Applications. Files downloaded this way aren't flagged, so macOS doesn't prompt. Read the script first if you like.

curl -fsSL https://jfinchy.github.io/mouthpiece/install.sh | sh

Build from source

Anything you build on your own Mac runs without the prompt. You'll need Rust and Bun; the steps are in the README.

git clone https://github.com/JFinchy/mouthpiece
